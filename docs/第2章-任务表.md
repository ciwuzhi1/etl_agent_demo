## B. 三件最容易搞混的事（大白话）

**PostgreSQL、Checkpoint 库、Redis 有什么区别？** PostgreSQL 是账本，记"哪个版本被冻结、谁批的、提交过没有"，这些必须永久可查；Checkpoint 是草稿纸，记 Agent 对话走到哪一步，目的是断电后能接着想，它**不是**审批证据；Redis 是传话的对讲机，只负责把活派出去、把结果捎回来，对讲机不记账。三者搞混的典型事故是：用 Redis 当账本，重启丢审批；用 Checkpoint 当审批真相，恢复出的状态没有法律效力。

**为什么 `.env` 不能提交、`.env.example` 可以？** 区别只在有没有真值。example 里全是空占位和本地默认值，抄来抄去不泄密；`.env` 里有一条能解开所有数据库口令的 Fernet 主密钥，进了 Git 就等于把钥匙插在门上，而且历史提交里删不干净。

**`/health` 的 `configured=true` 到底证明了什么？** 只证明"必要配置存在且格式可用"。它**不**证明 PostgreSQL 已建表、Redis 能投任务、也不证明这把密钥能解开历史上存的密文。所以本章还要单独做容器与 Session 验证，别拿一个绿灯当全绿。
